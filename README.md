# Examzone Blog Portal

A full-stack blog management portal with admin dashboard and responsive frontend.

## Features
- Admin login panel
- Add/Edit/Delete blogs
- Rich text editor support
- Blog categories and filters
- Responsive design for mobile and desktop
- Read More functionality for blogs

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

## Installation & Setup

### Clone Repository
```bash
git clone https://github.com/divyanshir84-droid/examzone-blog-portal.git
```

### Navigate to Server Folder
```bash
cd server
```

### Install Dependencies
```bash
npm install
```

### Run Server
```bash
node server.js
```
